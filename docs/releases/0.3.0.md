## Compatibility and release contents

The release adds recovery, checkpoint backup/restore, bounded enumeration and I/O,
and durability ordering. Contract and schema versions remain 1.0.0. Existing
0.1.0 and 0.2.0 records remain readable; new records identify tool version 0.3.0.
The explicit POSIX Kujo 1.5.0 source-revision requirement remains documented in
README, release notes, ecosystem page, docs page, and MCP scope metadata. The
semantic version alone does not guarantee the required preview APIs.

Version markers, manifest, schema, README and CLI agree. Regression coverage now
includes both old record versions and all release markers. The full local gate
passed 225 assertions plus JSON/launcher checks. `kennel validate` also passed.
The registry manifest makes this release publishable without a new legacy
manifest projection or edits to immutable old distributions.
